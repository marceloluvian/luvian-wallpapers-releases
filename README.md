# Luvian Wallpapers for Mac

An interactive wallpaper for your Mac.

**[Download the latest version](https://github.com/MarceloLuvian/luvian-wallpapers-releases/releases/latest)**

- Apple Silicon Mac (M1 or newer) and macOS 13 or newer.
- Open the DMG and drag the app to Applications.
- It updates itself: you'll get a heads-up when a new version is out.
